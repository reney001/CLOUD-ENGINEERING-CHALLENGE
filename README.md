 Cloud Engineering Questions

1. What is cloud computing?
Cloud computing is the delivery of computing services like servers, storage,
and networking over the internet, allowing users to access resources
on demand without owning physical hardware.

2. What is DevOps?
DevOps combines software development and IT operations to automate
processes and deliver software faster and more reliably.

3. Difference between Docker and Kubernetes?
Docker creates and runs containers that package an app and its dependencies.
Kubernetes manages and orchestrates multiple containers across many servers,
handling scaling and availability.

4. Why are Linux skills important in cloud engineering?
Most cloud servers run on Linux. Cloud engineers use Linux to manage
servers, run scripts, and configure systems — making it a core skill
in cloud environments.
